# GenLayer Orbital Spinner

A polished, brand‑conscious loading spinner designed for the GenLayer Portal.  
It uses only SVG and CSS keyframe animations – no JavaScript is needed to run the spinner. The demo page includes JS toggles for background and size, but the core asset is 100% vanilla.

## Features

- Pure SVG + CSS – works everywhere, lightweight (about 3 KB gzipped).
- Infinite, smooth loop – three counter‑rotating rings with orbital dots.
- GenLayer identity – hexagonal core with subtle pulsing and floating nodes.
- Works on any background – gradients adapt to dark and light modes out of the box.
- Responsive – scales elegantly from tiny to large sizes.
