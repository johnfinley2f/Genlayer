# GenLayer Spinner · UI Component for dApps

A zero-dependency, production-ready loading spinner built for the GenLayer ecosystem. It helps developers add branded loading states to their intelligent contract frontends. This component is already adopted as the official Portal loader.

## Features

- Pure HTML + CSS + SVG — no JavaScript needed.
- Works on dark and light backgrounds.
- Scales cleanly from small to large.
- Single file — drop it into any project.

## Usage

Copy the `<svg>` block and the associated CSS keyframes into your project. The spinner is fully self-contained.
